每次写入和读取时，都至少使用两个页，一个页作为主页，另一个页作为备份，防止写入和读取时突然断电导致数据丢失。

| page | 说明     |                 |                 |     |     |
| ---- | ------ | --------------- | --------------- | --- | --- |
| 0    | 作为目录页  | 2 byte 当前写入的页地址 | 1 byte 数据是否有效标志 |     |     |
| 1    | 作为目录页  | 2 byte 当前写入的页地址 | 1 byte 数据是否有效标志 |     |     |
| 2    | prev 页 | 4 byte 大计里程     | 4 byte 小计里程     |     |     |
| 3    | prev 页 | 4 byte 记录擦写次数   | 1 byte 数据是否有效标志 |     |     |
| 4    | next 页 | 4 byte 大计里程     | 4 byte 小计里程     |     |     |
| 5    | next 页 | 4 byte 记录擦写次数   | 1 byte 数据是否有效标志 |     |     |
| ...  |        |                 |                 |     |     |
|      | prev 页 | 4 byte 大计里程     | 4 byte 小计里程     |     |     |
|      | prev 页 | 4 byte 记录擦写次数   | 1 byte 数据是否有效标志 |     |     |
|      | next 页 | 4 byte 大计里程     | 4 byte 小计里程     |     |     |
|      | next 页 | 4 byte 记录擦写次数   | 1 byte 数据是否有效标志 |     |     |
